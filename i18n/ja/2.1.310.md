- Bedrock、Vertex、Foundry 上、およびテレメトリや不要なトラフィックが無効化されている環境において Monitor ツールとプラグインモニターを追加。また、これらの環境でフォアグラウンドの長時間のスリープをブロックするように変更
- `effort-2025-11-24` ベータ値や会話途中のシステムメッセージを拒否する一部のゲートウェイや互換サーバーの配下でリクエストが失敗する問題を修正。Claude Code がこれらを除外してリトライするように改善
- `cleanupPeriodDays` に非常に大きな値が設定されている場合、バックグラウンドのクリーンアップ処理によって貼り付けられた画像などの最近のファイルが削除されてしまう問題を修正
- 「Prompt is too long」エラー後のコンパクション処理において、Base64 や SVG などの高密度テキストを含む会話を過剰に保持してしまい、次のリクエストが再度失敗する可能性があった問題を修正
- ファイル読み取りのパーミッション確認プロンプトで、シンボリックリンクのリンク先が表示されない問題を修正
- 長時間の編集後に外部エディタを閉じた瞬間に、質問の自動継続タイムアウトが発火してしまう問題を修正
- Windows: Git Bash が存在せず、フックのコマンドが引用符付きパスなどの引用符付き文字列のみで構成されている場合に、PreToolUse および PermissionRequest フックがツール呼び出しを通過させてしまう問題を修正
- 作業ディレクトリ外の最初の読み取り前に表示される auto mode のプロンプトを改善: これらの読み取りをブロックするとシェルコマンド側でパーミッション確認が求められる旨を明記するように変更
- トランスクリプトファイルが非常に大きい場合における、コンパクション中の非対話型セッション（`-p`、Agent SDK）のメモリ使用量を改善
- kitty、Ghostty、およびフルスクリーンレンダリング有効の iTerm2 3.5+ において、`allow-passthrough` と `focus-events` を有効にした tmux 内で mod の `Image` が `alt` テキストしか表示されなかった問題を改善し、正常に描画されるよう修正
- Linux: bubblewrap によるサンドボックスの起動が阻害されている場合、`/sandbox` およびサンドボックス起動時の警告メッセージで Ubuntu のユーザー名前空間に対する AppArmor の制限と、その解除方法を提示するように改善
- 非対話型セッション中にサーバーの引き出し（elicitation）への応答がないまま MCP ツール呼び出しがタイムアウトした際のエラーメッセージを変更: 応答がなかったこと、および呼び出しを再試行しないよう Claude に伝えるように変更
- [VSCode] プランレビューカードの「Send feedback and keep planning」ボタンで Enter キーを押した際、コメントを送信する代わりにプランが承認されてしまう問題を修正
- [VSCode] セッション履歴の Web タブから開いたクラウドセッション上で「Switch branch & continue」を実行した後に、パネルに「Something went wrong」と表示される問題を修正
- [Cloud sessions] Enterprise のカスタムロールに Claude Code クラウドセッションと Remote Control の権限を追加し、Owner がロールごとに各アクセス権を制御できるように変更
- [Cloud sessions] クラウド環境のセットアップスクリプトをファイルから読み込むための Choose file ボタンを追加
- [Cloud sessions] クラウド環境の編集ダイアログで保存やアーカイブに失敗した際、ダイアログ内にエラーが表示されない問題を修正
- [Cloud sessions] ルーチンの API トークン操作に失敗した際にトースト通知のみが表示されていた問題を修正。ルーチン編集ダイアログ内にエラーが表示されるように変更
- [Cloud sessions] セッション開始チェックリストを改善し、クラウド環境のセットアップスクリプトの出力をスクロール可能なボックス内に表示するように変更
- [Cloud sessions] 管理者設定で Cloud sessions または Remote Control を有効化する際、確認を求め、その権限を持つカスタムロールの一覧を表示するように変更
- [Cloud sessions] クラウド環境ダイアログを変更し、すべてのエディタを一度に一覧表示する代わりに、行からネットワークアクセス、セットアップスクリプト、環境変数を開くように変更
- [Claude Tag] 太字、斜体、取り消し線で送信された場合に、Claude Tag が `!restart` や `!help` などの `!` コマンドを通常のメッセージとして扱ってしまう問題を修正
- [Claude Tag] バンドル一覧のバックグラウンド更新が失敗した際に、Claude Tag の管理チャンネルおよびワークスペースページが読み込みエラー画面に置き換わってしまう問題を修正
- [Claude Tag] チャンネル名の読み込み中に、管理者設定の Claude Tag 利用制限ページでフィルタに一致するチャンネルがないと報告されてしまう問題を修正
- [Code Review] リポジトリ一覧の更新に失敗した後に、Code Review 管理セクションのリポジトリとスイッチが非表示になってしまう問題を修正
- [Code Review] Code Review 管理セクションを改善し、初回読み込みの再試行を行うとともに、それでも失敗した場合は Try again バナーを1つ表示するように変更
