- ターミナルセッションに合わせて、Claude Desktop および Cowork が Claude apps gateway 経由で送信するテレメトリに `user.email` と `user.groups` を追加
- `--plugin-dir` にプラグインのフォルダを指定するサポートを追加: マニフェストを持つ各サブフォルダが読み込まれ、実行中に追加または削除されたサブフォルダも反映されます
- ディスクに保存されるツール結果に 1 GB の上限を追加。保存されたファイルが切り捨てられた場合、会話内のプレビューに表示されるようになりました
- フォアグラウンドで生成されたサブエージェントの再開時にツールリストとシステムプロンプトのプレフィックスが変更され、そのエージェントの prompt-cache の再利用が壊れる問題を修正
- エージェントのチームメイトおよび再開されたサブエージェントが、以降のターンで SubagentStart フックのコンテキストと事前ロードされたスキルをプロンプトプレフィックス外に移動してしまい、prompt-cache の再利用が壊れる問題を修正
- ツール実行中に直前のプロセスが異常終了した後の再開処理を修正: 最後のプロンプトが書き直されなくなり、中断されたツール呼び出しは保持されて中断扱いとしてマークされます
- `/model opusplan[1m]` が "Model not found" で拒否される問題を修正
- 権限確認プロンプトやメッセージ内のシンタックスハイライトされたコードで、Ruby の `?`、Erlang の `$`、または Perl の `$` シジル（記号）の後の文字が欠落することがある問題を修正
- スラッシュコマンドまたは @-file のサジェストリストが開閉するたびに、フルスクリーントランスクリプトが 1 行ずれる問題を修正
- macOS および Linux で、バックスラッシュを含むプラグインパスがシンボリックリンクの包含チェックをバイパスする問題を修正
- 名前が 2 つのドットで始まるプラグインディレクトリが、プラグインルート外として誤って拒否される問題を修正
- トークンのリフレッシュ中にセッションが閉じられた際、VS Code および SDK セッションで再ログインが必要になることがある問題を修正
- Remote Control セッションが返信の最後のメッセージの前にターン終了シグナルを送信し、最後の部分が届く前に Claude アプリ上で返信が完了したように表示されることがある問題を修正
- アイドルタイムアウトの直前にメッセージが到着した際、バックグラウンド（`--bg`）セッションがターンの途中で終了されることがある問題を修正
- Claude Code 自身の git status および diff プローブが、作業ツリー内のネストされたリポジトリによって設定された clean フィルターを実行してしまう問題を修正
- advisor ツールとその指示がリクエストのモデルからリクエストごとに再決定されていた問題を修正。決定は 1 回のみ行われ、変更された場合に会話内で通知されるようになりました
- アーティファクトの公開で、コネクターが公開していないコネクターツール名を受け入れてしまう問題を修正。宣言されたツールがまったく存在しない場合は公開が拒否され、一部のみ存在しない場合は警告が表示されるようになりました
- 管理設定でプラグインに対してスキルのみがロックされている場合に `/add-dir <subdirectory>` がサブディレクトリのエージェントの読み込みを拒否し、エージェントのみがロックされている場合にエージェントの読み込みを保証してしまう問題を修正
- tmux 内などで 2 つ目のキー入力が 1 秒以上遅れた場合に、2 キーのキーボードショートカットが無言でキャンセルされる問題を修正。3 秒間待機し、タイムアウト時に通知が表示されるようになりました
- フォークされたスキル（`context: fork`）で、開始プロンプト、および `--forward-subagent-text` 指定時のテキストターンが stream-json の進捗イベントとしてストリーミングされない問題を修正
- シンボリックリンクのループなど、OS がチェックできないプラグインのデフォルトコンポーネントフォルダが無言でスキップされる問題を修正。`/plugin` でエラーコードとともに報告されるようになりました
- Claude apps gateway の OTLP テレメトリリレーが、不正な形式または大きすぎるペイロードをいくつか拒否した後に、コレクターへのすべての転送を 30 秒間一時停止する問題を修正
- メタデータが `plugin.json` 内にのみ存在するマーケットプレイスプラグインにおいて、`/plugin` の Discover/Browse および `claude plugin list --json --available` で説明や表示名が表示されない問題を修正
- 管理設定で指定された Claude apps gateway にサインインしたセッションで `/login` を再実行した際、"no gateway URL is configured" と表示される問題を修正
- 設定ファイルに書き込めない場合でも、`/model` がモデルを "saved as your default" と表示していた問題を修正。保存に失敗したこととその理由が表示されるようになりました
- Remote Control からの `/clear` が完了前に SessionStart フックおよび開いているターミナルダイアログを待機してしまう問題を修正
- `/config` ダイアログのタブを切り替える際にダイアログの高さが変わる問題を修正
- コンテナ再起動後のワークフロー実行の再開処理を修正。実行ジャーナルが見つからない場合の再開は、すべてのエージェントを再実行するのではなく、明確なエラーで失敗するようになりました
- `claude-api` スキルのエラーコードリファレンスを修正: モデルアクセス失敗時は 404、利用不可能なベータヘッダー時は 403 ではなく 400 を返します
- 非対話型セッション（stream-json 入力を伴う `-p`、Agent SDK、クラウドセッション）で、新しいユーザーメッセージごとにシェルの作業ディレクトリがリセットされる問題を修正。`cd` がターンをまたいで維持されるようになりました
- レガシーな HTTP+SSE トランスポートのみをサポートする `http` として設定された MCP サーバーが接続できない問題を修正。MCP 仕様に従って Claude Code が SSE にフォールバックするようになりました
- クラウドセッションで一部の claude.ai コネクターが claude.ai に接続されているにもかかわらず認証が必要と表示される問題を修正（未対応のリクエストに HTTP 401 で応答するサーバー）
- リモートセッションがコネクターの承認またはサインインリンクの入力待ちの間、サンドボックスコンテナを起動したまま維持してしまう問題を修正
- 再開されたセッションにおいて、「バックグラウンドタスクが完了しませんでした」という通知に短いステータス行ではなく、モデル向けの長いリカバリ手順が表示される問題を修正
- Windows: AppContainer または制限付きトークンのサンドボックス内で実行されている場合、Read、Write、Edit がすべてのファイルを拒否する（"symlink resolution changed after permission was checked"）問題を修正
- 大規模リポジトリにおける `--worktree` の起動を改善: 新しい worktree が並列でチェックアウトされるようになりました（git 2.32+）
- `/workflows` のエージェント詳細を改善: ツール呼び出しが実行中、失敗、完了としてマークされ、サブエージェントにタスクリストがある場合はそれが表示され、Enter キーで一覧表示された呼び出しの入力と結果を展開できるようになりました
- プロンプト入力途中のスラッシュコマンドの挙動を改善: 単一のサジェストではなく一覧で一致候補が表示されるようになり（フルスクリーン外では Tab で開く）、プラグインスキルが単独の名前で検出されるようになりました
- サインインが必要なリモート MCP サーバーを改善: 実際に認証を行うまで、Claude Code はそれらに対して OAuth クライアントを登録しなくなりました
- 多数のファイルを読み込んだ長時間のセッションを再開する際の所要時間を改善
- サイズ制限を超えた画像をデコードできない際のエラー表示を改善: 制限を引用するだけでなく、原因と解決方法を表示するようになりました
- 他者が作成したアーティファクトに対する Artifact ツールの読み込みを改善: 要約でページを信頼できないコンテンツとして扱い、埋め込まれた指示をそのまま中継するのではなくフラグを立てるようになりました
- `.claude` フォルダの権限オプションを更新し、実際に許可される内容（そのセッション中、プロジェクトの `.claude` フォルダ（または `~/.claude`）内のファイルを編集すること）を明記するように変更
- 管理設定で `forceLoginGatewayUrl` が指定されているマシンを、`forceLoginMethod: "gateway"` と同様に起動時から Claude apps gateway セッションとなるよう変更。残存している claude.ai のログイン情報や API キーは使用されません
- 画像処理をランタイム組み込みの画像サポートを使用するように変更。CLI が一時ディレクトリにネイティブ画像モジュールを展開しなくなりました
- プラグインの表示メタデータを変更し、Installed タブおよび `claude plugin details` において `plugin.json` よりもマーケットプレイスのエントリを優先し、不足している情報を `plugin.json` で補完するように変更
- Claude apps gateway セッションにおいて、gateway のリレー経由ではなく、gateway の管理設定の `OTEL_EXPORTER_OTLP_ENDPOINT` で指定されたコレクターへ直接 OpenTelemetry をエクスポートするように変更。指定されたコレクターがないセッションは引き続きリレーを使用します
- [VSCode] 一定期間非アクティブなセッションの自動アーカイブ機能を追加（新しい "Archive inactive sessions" 設定、デフォルト 14 日）
- [VSCode] 会話が 10 分以上開かれていた場合に、Reload Window または再起動後にサイドバーチャットが空白になる問題を修正
- [VSCode] "Remote Control is active" メッセージで、タイムラインのドットがテキストの下に配置されてしまう問題を修正
