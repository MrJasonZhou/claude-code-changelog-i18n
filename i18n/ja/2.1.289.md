- 管理対象マシンにおいて、複合シェルコマンドのネストされた部分に対する deny または ask ルールが、ユーザーがインストールした mod の承認より優先されない問題を修正
- 多数の閉じられていない `<script>` タグや深くネストされた `${` 置換を含む短いコードブロックで、ターミナルがフリーズする問題を修正
- シンボリックリンク経由でIDE内で@-メンション、変更、または選択されたファイルに対し、`Read` の deny ルールが適用されない問題を修正
- [VSCode] サインアウトが頻発する原因となっていた可能性がある、2.1.288 での `claude auth status` に対する変更を元に戻しました
- ハイライト表示のビューを最終的な幅で一度だけレイアウトすることで、プラグインのコードペインで大きなファイルが素早く開くよう改善
- ローカルフォルダのマーケットプレイスからインストールされたプラグインについて、`plugin list`、`plugin eval`、`plugin update` が古いコピーを表示する問題、およびシンボリックリンクされた `--plugin-dir` のホットリロードを修正
- アップグレード直後の最初のセッションで、インストール済み mod が読み込まれない問題を修正
- Background tasks ダイアログをフルスクリーンで開いている間、プロンプト上部のプラグインの行に古い行が表示される問題を修正
- リンクに localhost アドレス、パス内の `@`、大文字のホスト名、または `file:` パスが使用されている場合に、プラグインペインに何も描画されない問題を修正
- ユーザーがインストールしたプラグインによって、組織管理下の MCP サーバーのサインインツールの説明が上書きされてしまう問題を修正
- ターミナルが認識しない境界線スタイルでプラグインが Box を描画した際に、起動時にフリーズまたは強制終了する問題を修正
- プラグインのオンスクリーンハンドラーが非同期に例外をスローした際に、監視セッションおよびバックグラウンドセッションが終了する問題を修正
- 高さのないプラグイン領域が拡大し続けた場合に、インターフェースエラーでセッションが終了する問題を修正
- サンドボックスがコマンドを自動許可する設定の際、展開された値を持つ環境変数プレフィックスの背後にあるコマンド（例: `TZ="$HOME" rm -rf build`）を Bash の deny および ask ルールが見逃す問題を修正
- コマンドの前に単純な変数代入が置かれている場合、サンドボックスの自動許可下で Bash の deny または ask ルールがスキップされる問題を修正
- フォルダ内にマーケットプレイスのマニフェストも含まれている場合に、`claude plugin validate` がプラグインをスキップする問題を修正
- チームメイト向けの `agent.spawn`、プラグインフックイベント全体で共通の1つの agent id、および `$.agent.list()` での idle と waiting の状態を追加
- mod の `ui.render` フックが書き込んだ値によって描画中に行が例外をスローした際に、セッションが「unrecoverable interface error」で終了する問題を修正。エンジンが代わりに独自の行を描画するようになりました
- タブ、不要なエスケープ、C1 制御文字を含むテキスト、またはタブと CRLF 改行を含む短いテキストが、その下の行に重なって描画される問題を修正
- mod のペインやバンド内の右寄せコンテンツが、閉じるマークや `[-]` の下に入り込んで描画される問題を修正。これらはターミナルの端から1列分の余白を保持するようにもなりました
- mod の `Client` が描画中に失敗した際、その周囲に mod が描画したすべての表示が巻き込まれる問題を修正。単独で失敗し、`ui.fault` を発生させるようになりました
- `claude plugin validate` が Anthropic マーケットプレイス自体のプラグインで失敗する問題、および `--json` でクリーンな `plugin.json` を一覧表示するよう修正
- mod の描画に失敗したバンドが、その下にあるカードを一瞬退避させてしまう問題を修正
- プラグインコンポーネントが失敗した際、エラーにメッセージが含まれていないと理由として `Error` または何も表示されない問題を修正
- mod のバンドまたはペインの描画に失敗した際に作成者に表示される行を改善。mod の名前を表示し、何も描画されなかった旨を明示するようになりました
- 多数の閉じられていない `<script>` タグを含む短いコードブロックで、公開されたアーティファクトページが閲覧者のブラウザタブをフリーズまたはクラッシュさせる問題を修正
- ターミナルが描画中に例外をスローした後、mod の Client 領域がセッション全体にわたって失敗状態のままになる問題を修正
