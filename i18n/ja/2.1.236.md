- `ANTHROPIC_DEFAULT_MODEL` 環境変数を追加: 新規セッション開始時のモデルを設定可能に。なお `/model` での選択はこれを上書きし、（`ANTHROPIC_MODEL` とは異なり）再起動後も保持されます
- セッション間の `SendMessage` に `notify_when_idle` を追加: 同一マシン上の別の Claude Code セッションに対し、次回アイドル状態になった際に一度だけ通知を送信するよう要求可能に（オプトイン、1回限り、ポーリング不要、macOS および Linux）
- Sandbox: macOS において、ワイルドカードによる読み取り拒否ルール（例: `**/.env`）が許可された読み取り領域内でも優先され、一致したディレクトリ配下のコンテンツも対象になり、拒否対象ファイルをリネームしても回避できなくなりました
- セッションの切り替え先ディレクトリが削除された後に、クリップボードのコピー、バックグラウンドのハウスキーピング、バックグラウンドセッション、およびローカル MCP ログが破損する問題を修正（2.1.229 以降）
- フルスクリーンレンダラーが起動に1度失敗しただけで恒久的に失敗する問題を修正: 以降の起動ごとに終了するのではなく、クラシックレンダラーにフォールバックするようになりました
- `/model` ピッカーがターミナル画面の高さを超えて描画される問題を修正: ウィンドウに収まる数のモデルのみを表示し、残りはスクロールでアクセスできるようになりました
- 不正な終了タグによってメッセージ本文が summary フィールド内に残ってしまった場合に `SendMessage` の呼び出しが拒否される問題を修正
- サブプロセスの起動失敗時（例: Windows 相互運用が無効な WSL 上の `powershell.exe`）に未処理の promise rejection が発生する問題を修正（2.1.234 での先祖返り）
- ターミナルのリサイズ後、次の更新までフルスクリーンモードで新しく送信されたメッセージが表示されないことがある問題を修正
- フルスクリーンモードで、複数行プロンプトをクリアした後にプロンプト上部に空白の帯が残る問題と、ターミナルをリサイズして元に戻した際にペインが再描画されない問題を修正
- 起動時に managed-settings の承認プロンプトが表示されないことがあるにもかかわらず、最初のキー入力が承認としてキャプチャされてしまう問題を修正
- tmux（iTerm の tmux 連携）でターミナルタブのタイトルが跳ねる問題を修正: タイトルは 960ms ごとにアニメーションするのではなく、テキストが変更されたときのみ書き込まれるようになりました
- クラウド環境の一覧が空または不正な形式で返された際に、わかりにくいエラーが発生する問題を修正
- Remote Control の使用時、Fable 5 初回利用クレジット（usage-credits）プロンプトが無回答のまま 60 秒経過するとフォールバックモデルを自動選択してしまう問題を修正
- `~/.claude.json` にキャッシュされたゲストパスの特典情報が不正な形式の場合に、バックグラウンドエラーが繰り返し発生してスピナーのヒントが表示されなくなる問題を修正
- セッションの作業ディレクトリが削除された後、SDK / VS Code セッションでの skills のホットリロードが skills の変更ごとにエラーを発生させる問題を修正（2.1.229+）
- アイドル、リタイア、または起動タイムアウトで解放されたセルフホストランナーのセッションが、post-session hook の完了前に別のランナーで再開されてしまうことがある問題を修正
- 一部のフォントサイズにおいて、iTerm2 でマスコットの Clawd の目と足が不均一に描画される問題を修正
- セッションの要約（recap）が暴走することがある問題を修正: 要約テキスト（自動生成および `/recap`）は単語境界で切り詰められ、最大 400 文字に制限されるようになりました
- 起動パフォーマンスを改善: セッションカウンターがバックグラウンドで書き込まれるようになりました
- auto mode を改善: auto mode がアクティブな間は `Monitor` の許可ルールが無効化され、Monitor コマンドが Bash コマンドと同様にレビューされるようになりました
- Bedrock、Vertex AI、Foundry、およびテレメトリ無効時における auto mode を改善: 分類器が重大度スコア付きの分類を含め、Claude API と同じデフォルト値を使用するようになりました
- auto mode を改善: リポジトリの `status.showUntrackedFiles=no` 設定によって git status チェックが誤認され、クリーンなツリーとして報告されることがなくなりました
- `/model` ピッカーを変更し、最新モデルの名前のみをハイライトするように修正: リストの任意のサブセットではなく、新リリースを識別できるようにハイライトされます
- `/goal`: 長時間実行されるバックグラウンド作業の完了待ちで保留になっているアイドルセッションが、ユーザーの復帰を待つ代わりに 30 分後（その後は 1 時間後、2 時間後）に自動でチェックインするようになりました
- `/usage` で Team および Enterprise メンバー向けに使用クレジット消費行を表示し、消費が発生する前には 0% の上限行を表示するようになりました
- print / SDK モードでの SIGTERM 受信時に、終了前の中断ターンや疑似的なツール拒否が記録されなくなりました。実行中のコマンドは引き続き終了され、プロセスは終了コード 143 で終了します
- スラッシュコマンドの誤入力や現在のセッションで利用できないコマンドで Enter キーを押した際、類似するファジーマッチを実行する代わりにエラーを報告するようになりました（プレフィックスおよびエイリアスは引き続き実行されます）
- Remote Control において、CLI の終了時またはターミナルのクローズ時に数秒以内にセッションをオフラインとしてマークするようになりました
- 短時間のバースト送信によってセッションのインボックスの許容量を超えそうな場合、破棄されたメッセージを送信済みとして報告する代わりに、`SendMessage` が事前に追加メッセージを拒否するようになりました
- プロンプト枠線上のセッションタイトルチップをフッターの右端と揃えました
- 右揃えのフッター項目（ゴールインジケーター、セッション状態、バックグラウンドエージェントの状態）および省略表示の通知が、プロンプト領域の他の部分と統一された右マージンを共有するようになりました
- [VSCode] トランスクリプトのスクリーンリーダー対応を追加: 返答、権限リクエスト、エラー、状態変更のライブ通知に加え、ターンごとの見出しナビゲーションをサポート
