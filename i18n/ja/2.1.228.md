- まれな内部レイアウトエラーの発生後、プロセスが実行中であるにもかかわらず、インタラクティブセッションの再描画が完全に停止することがあった問題を修正
- Windows において、git インストール先の親フォルダーから Claude Code を起動した際に `git` / Git Bash が見つからない問題を修正
- 前回のレスポンス以降に `/model` を変更していた場合、`/tui` によってセッションが以前のモデルに戻ってしまう問題を修正
- インストールまたはアップグレード後の最初のセッションで、クロスセッションメッセージングが受信トレイなしで開始されることがあった問題を修正
- 接続中に Remote Control の `/resume` を実行すると、再開された会話のタイトルや履歴が接続中のセッションに漏出してしまう問題を修正
- セッションがプッシュを行わないリポジトリで `checkout` フックが失敗した際、新規ランナーごとに `claude self-hosted-runner` セッションが失敗していた問題を修正。該当リポジトリは警告を表示してスキップされるようになりました
- セルフホストランナーにおいて、バックグラウンドタスクの完了から次のターンの開始までの合間にセッションが終了してしまう問題を修正
- セッションのクリーンアップによってプロジェクトの memory フォルダー内のコンテンツが削除されてしまう問題を修正
- バックグラウンドのプラグインキャッシュのクリーンアップによって、プラグインの唯一のバージョンがシンボリックリンクされた開発用チェックアウトである場合にそのキャッシュが削除されてしまう問題を修正
- 優先度の高い設定階層で再定義されたマーケットプレイスエントリが別の階層のカスタムヘッダーを継承してしまう設定マージの問題を修正。マーケットプレイスエントリは全体としてマージされるようになりました
- スキルの呼び出し後、遅延ツールのリマインダーがモデルに誤って2回送信されることがあった問題を修正
- claude.ai から同期されたスキルのセキュリティを強化: ローカルコマンドや MCP プロンプトをシャドウイングしなくなり、説明がサニタイズおよびラベル付けされ、ローカルマシン上でその本文から `!` コマンドの実行や `@` ファイルの展開が行われなくなりました
- クロスセッションメッセージの改善: 折りたたまれた行ではなく送信者と本文がインラインで表示されるようになり、別マシンの Remote Control セッション宛のメッセージには送信者として自身の Remote Control セッション名が表示されるようになりました
- Vertex AI の認証情報処理を改善: 有効期限切れまたは見つからない Google Cloud の認証情報は、数分間リトライするのではなく数秒で失敗するようになりました
- コンパクションの進行状況表示を改善: プログレスバーのみの表示から、リトライカウントダウンとストール時のヒントもコンパクション中に表示されるようになりました
- 一部のターミナルにおけるタブバーのちらつきを軽減するため、ターミナルタイトルのビジースピナーのグリフを更新
- Edit ツールのルールに合わせて、より新しいモデルでは現在のセッションで読み取っていない既存ファイルを Write ツールで上書きできるように変更。従来のモデルでは引き続き事前の読み取りが必要です
- Pro、Max、Team プラン向けの初回利用通知から、auto mode セッションの費用がわずかに高くなるという古い記述を削除
