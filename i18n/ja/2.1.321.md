- Gateway: Bedrock、Vertex、Foundry の各アップストリームが、ゲートウェイの環境変数内の `ANTHROPIC_*_BASE_URL` を無視するように変更。別のエンドポイントを使用する場合はアップストリーム側で `base_url` を設定してください
- ヘッドレスセッションにおいて、`.claude/skills` 内のファイルが変更された際に mod を再読み込みするように変更。無効化するには `CLAUDE_CODE_PLUGIN_DIR_WATCH=0` を設定
- サイバーセーフガードによるブロック時の Cyber Verification Program に関する文言を、claude.ai と同一の表現を使用するよう変更
- Cowork クラウドセッションの動作を変更: PostToolUse フックが AskUserQuestion への回答や ExitPlanMode の結果に含まれる計画を置換できないようにし、Claude が元の内容を読み取るように変更
- `/bin/cp` のようにフルパスで指定された `cp` および `mv` に対しても、通常の `cp` や `mv` と同様のパスチェックを適用するように変更
- バックグラウンドコマンドの通知および TaskStop の結果において、1,000 文字を超えるコマンドは先頭と末尾のみを Claude に表示するように変更し、コンテキスト消費を抑制
- アーティファクトの設計ガイドラインを変更し、Inter と Space Grotesk を適切なデフォルト書体として扱うように変更
- アカウントのメールアドレスチェックを変更し、メールアドレスを含みかつ User-Agent を指定しているシェルコマンドのみを確認なしで拒否するようにし、他のコマンドや定期実行がプロンプトで停止しないように変更
- Remote Control セッションが開始時のフォルダを維持するように変更: 接続されたクライアントがセッションを別のフォルダに移動できないように変更
- 未宣言のソースからの管理対象 `extraKnownMarketplaces` 乗っ取り時の挙動を変更: 保存データは `cleanupPeriodDays` の間退避され、オプションとシークレットは `claude plugin restore-set-aside` の実行まで退避されるように変更
- [VSCode] 認証トークンと API キーの両方が設定されている場合、ターミナルの起動時警告に合わせて、プロンプトボックスの上部に警告を表示するように追加
- [VSCode] プラグインの権限リクエストで非表示文字を含む名前が表示されていた問題を修正。「a plugin」と表示されるように変更
