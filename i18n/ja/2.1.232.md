- サブエージェントのフォークがデフォルトで有効化: `subagent_type: "fork"` のサブエージェントは会話全体とプロンプトキャッシュを継承し、インタラクティブセッションでの非チームメイトエージェントの生成はデフォルトでバックグラウンド実行されるようになりました
- プロンプトで `@` を入力して別の Claude セッションを名前でメンション可能に。Claude は `SendMessage` を使用してそのセッションに直接接続します
- `SendMessage` は、最初に参照の確認を求める代わりに、アクティブな1つのセッションと完全に一致する単一の名前へ直接配信するようになりました
- 同一マシン上のインタラクティブセッションが一意な名前を維持するように変更: 既に別のアクティブなセッションが使用している名前でセッションを開始または名前変更した場合、`name-word-word` 形式のバリアントが付与され通知されます
- `/config` に「Dialog expiry」および「Messages from your other sessions」（セッション間のインバウンド受信 accept/hold/refuse）の項目を追加
- GitLab トークンファミリー（`glrt-`、`gloas-`、`glptt-`、`glagent-`、`glimt-`、`glsoat-`、`glcbt-`、`glft-`、`glffct-`）のシークレットマスキングとルーティング可能な `glpat-`/`gldt-` トークンの完全マスキングを追加。`glab` CLI の設定ストアは `gh` と同じサンドボックスおよび認証情報パス保護が適用されます
- プラグインマーケットプレイスに GitLab のサポートを追加: 単体の `gitlab.com` リポジトリ URL（ネストされたサブグループを含む）が `github.com` URL と同様にクローン可能になり、クローン認証失敗時のヒントに実際の git ホスト名が表示されます
- 設定: `additionalMarketplaces` と `allowedMarketplaces` が、`extraKnownMarketplaces` と `strictKnownMarketplaces` のより分かりやすいエイリアスとして受け入れられるようになりました
- エンタープライズポリシー: 単体リポジトリ URL に対する URL 形式の `blockedMarketplaces` エントリは、CLI がそれを git clone と分類した場合でも引き続きその URL をブロックします
- Gateway: `desktop:` オーバーレイがリリース済みのすべての Desktop 設定（以前は手動指定の11キー）を受け入れるようになり、起動時に Desktop 独自のスキーマに対して検証されます。不明または無効なキーがある場合は起動に失敗します
- Gateway: 空の `managed.policies[].match.groups`/`admin.admin_groups` エントリや不正な `email_domain` の値（空、または `@`、空白、カンマを含む）は、サイレントに誰にも一致しなかったり管理者アクセスを付与したりする代わりに、起動時にエラーを発生させるようになりました
- Fable へのアクセス権を持つ組織向けに、`/advisor` のアドバイザーとして Fable 5 を再提供。使用クレジットの同意は `/model fable` で設定可能です
- 変数書き込みパラメータが `$PSDefaultParameterValues` をサイレントに上書きし、後続コマンドのファイルアクセスをリダイレクトできる PowerShell の権限バイパスを修正
- パス検証で通常ファイルと見なされた Cygwin スタイルのシンボリックリンクを Git Bash が追従してしまう Windows の権限バイパスを修正。これらを経由した書き込みには権限の承認が必要になりました
- ネストされた git リポジトリが親ディレクトリから信頼を継承する問題を修正。各リポジトリで個別の信頼確認が必要になりました
- サーバーが応答しない場合やプロトコルバージョン検出に不正な応答を返した場合に、MCP 接続が30秒の接続タイムアウト全体にわたってハングする問題を修正
- クラウドセッション内のブリッジによってホストされている Remote Control セッションが、そのセッションのトランスクリプトや認証情報を継承する問題を修正
- Claude Desktop または IDE から開始された Remote Control セッションが、ローカルセッションの再開時に毎回新しい claude.ai セッションとして表示される問題を修正。既存のセッションに再接続するようになりました
- アイドル中、新たに接続したクライアントから Remote Control セッションが到達不能に見える問題を修正
- セッションワーカーの再起動時に、Remote Control ブリッジセッションが会話履歴を復元しない問題を修正
- Remote Control: claude.ai またはアプリからセッションが削除された会話を再開する際、ログインに関するエラーメッセージで失敗する代わりに代替セッションを開始するようになりました（v2.1.227 でのデグレード）
- マネージド設定の読み込みに失敗した際、Cloud gateway の `/login` がサイレントに終了するか、「Press Enter to continue」の後にターミナルが応答しなくなる問題を修正。理由が表示されるようになりました
- 音声サービスが接続を拒否した際、ネイティブビルドのボイスモードが「listening…」のままスタックする問題を修正。拒否された旨が即座に表示されるようになりました
- mTLS クライアント証明書のローテーション時に再起動が必要だった問題を修正。Claude Code は接続エラー時にローテーションされた証明書とキーを自動的に再読み込みします
- リクエスト URL の構築に不正な AWS または Vertex のリージョン値が使用されていた問題を修正。デフォルトのリージョンにフォールバックするようになりました
- Bedrock、Vertex、および gateway デプロイメントにおいて、ストリームのアイドルタイムアウトエラーが発生した際に回復せずリクエストが失敗する問題を修正
- 切り詰められたテキストを含むコンテンツサイズのオーバーレイが1列広くレンダリングされる問題、および先頭が切り詰められたテキストが省略記号に縮小される問題を修正
- 長いシェルコマンドまたはエージェント説明のプレビューが絵文字の途中で切断された場合に、余分な文字化けが発生する問題を修正
- `known_marketplaces.json` への同時書き込みにより、プラグインマーケットプレイスの登録がサイレントに解除される可能性があった起動時の競合を修正
- 再起動後も維持されるタスクが実行中の場合に、`/update` および `/tui` が再起動を拒否する問題を修正
- SDK およびリモートセッションにおいて、利用できないスラッシュコマンドを使用量制限のガイダンスが提案する問題を修正
- インタラクティブな `--advisor fable` の起動時における同意メッセージで、終了したばかりのインタラクティブセッションで `/model fable` を実行するよう案内される問題を修正
- フルスクリーンストリーミングの改善: 更新ごとに会話全体が再正規化されなくなったため、長時間のセッションでも応答性を維持
- マネージド設定の承認ダイアログを改善: エンドポイント URL を表示し、テレメトリのみの変更に対してより明確な文言を使用、定期的な OpenTelemetry オプションをスキップし、サーバー管理のサンドボックスバイナリオーバーライド（`sandbox.bwrapPath`、`sandbox.socatPath`、`sandbox.ripgrep`）に承認を要求するように変更
- Claude が応答中に呼び出された場合でも、ターンの終了を待たずに `/feedback` と `/bug` が即座に開くようになりました
- `/plugin install plugin@marketplace` は最初にマーケットプレイスを更新するようになり、手動でマーケットプレイスを更新しなくても新規公開されたプラグインをインストール可能に
- high、xhigh、max effort での `/code-review` が、他のレベルと同様にバックグラウンドエージェントで実行されるようになりました
- 貼り付けられた画像およびクリップボードの画像をイベントループをブロックせずに読み取るように改善
- Remote Control は一時的なネットワーク障害後、約30分間再接続を試行し続けるようになり、1時間に数回の一時的な障害が発生しても切断されなくなりました
- Remote Control: 会話を再開しても、同一マシン上で Remote Control を保持している別の Claude Code からサイレントに権限を奪うことがなくなりました。移動するには対象側で `/remote-control` を実行してください
- エージェントパネルを更新: 完了したサブエージェントは `/tasks` のフッターヒントとともに即座に非表示になり、「↓ N more」オーバーフローインジケーターの視認性向上のため左側に移動
- Remote Control: セッションが別のデバイスに乗っ取られたか、別のアプリから終了されたか、削除されたかがターミナルに表示されるようになり、それを元に戻してしまうような再接続の提案を停止
- Bash の入力リダイレクト（`< file`）が、すべてのプラットフォームで引数指定と同様に権限チェックされるようになりました
- 完了したバックグラウンドエージェントを再開した際に表示されるメッセージを短縮
- Cowork セッションがユーザースコープのメモリファイルから外部の @-import をインライン展開しないように変更
- 共有 `/tmp` 上で自動生成されるセッション間メッセージングソケットディレクトリを堅牢化: 事前に仕込まれたシンボリックリンクや他のユーザーのディレクトリは使用されず拒否されるようになりました
- 保護されたパスのバイパスに対し、Linux ファイルシステムサンドボックスを堅牢化
- `sandbox.ripgrep` は user、managed、`--settings` の設定からのみ適用されるよう変更。プロジェクト設定からサンドボックスの ripgrep バイナリを上書きできなくなりました
- カスタムサブエージェントの作成を提案する起動時ヒントと、`/powerup` ツアーの該当ナッジを削除
