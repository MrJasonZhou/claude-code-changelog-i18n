- Linux 上のサンドボックス化されたコマンドがユーザー名前空間を作成できるように `sandbox.allowNestedUserNamespaces` を追加（Chromium、rootless podman）。これによりサンドボックスのファイル保護を回避できるようになります
- 無人リトライモード（`CLAUDE_CODE_RETRY_WATCHDOG`）がリセット前に解除された利用制限を検知できるように `CLAUDE_CODE_RETRY_WATCHDOG_USAGE_LIMIT_RECHECK_MS` を追加
- エンドポイントまたはゲートウェイが tool search を拒否した場合や、ToolSearch が不許可または `--tools` から除外されたゲートウェイ配下で、Vertex、Bedrock などのプロバイダーですべてのリクエストが失敗する問題を修正（2.1.304 のリグレッション）：Claude Code はこれを使用せずにリトライするようになりました
- モデル名の大文字・小文字の違いや `[1m]` タグによって `modelOverrides` の値と一致しない場合に、`/effort` および `/autocompact` の設定が適用されない問題を修正
- ベアリポジトリ内の新しい worktree がデフォルトブランチではなくローカルの HEAD から開始されることがある問題、および変更のないサブエージェントの worktree がクリーンアップされないことがある問題を修正
- ディスク容量不足時に Bash コマンドが生の `ENOSPC` ファイルパスで失敗する問題を修正：エラーメッセージにディスクが一杯であることと何も実行されなかったことが明示されるようになりました
- クラウドセッションまたは SDK の `setMcpServers` から渡された MCP サーバーが、セッションの途中で自身の設定にある同名のサーバーに置き換えられてしまう問題を修正
- サブエージェントがフォールバックモデルに切り替えた後、Claude がサブエージェントの作業に対して誤ったモデル名を報告する問題を修正
- コンパクションでサイズ内に収めるために最も古いメッセージを要約から除外せざるを得なかった際、クラウドセッションやチームメイトが Claude にその旨を伝えていなかった問題を修正
- スケジュールされた Cowork クラウドセッションで、誰も承認できない状況にもかかわらず、WebFetch の URL 承認を必要とする各サブエージェントが5分間待機してしまうケースをさらに修正
- Workflow の再開時、実行ジャーナルから結果を取得する代わりに、完了済みの `pipeline()` および `parallel()` エージェントを再実行してしまう問題を修正
- Remote Control で `/resume` を使って会話を切り替えた後、`/resume` に空の「(session)」エントリが残る問題を修正
- 幅の狭いターミナルで `/usage` の行が見切れてしまう問題を修正
- 起動時の警告がロゴの上に生テキストとして表示されていた問題を修正：デバッグログに出力されるようになり、何も制限していないパーミッションルールはバナーの下に警告行として表示されるようになりました
- スクリーンリーダーモードを修正：検索ボックスの表示が VoiceOver で「telephone recorder」と読み上げられていた記号から「Search:」に変更され、Ctrl+R の検索一致や「ultrathink」などのハイライトされたプロンプトテキストで単語内に空白が入らなくなりました
- Self-hosted runner：`TERM` が設定されている場合、ランナーまたはオーケストレーターと stdout のみを共有する起動スクリプトが `Resource temporarily unavailable` で失敗する問題を修正（2.1.300 のリグレッション）
- Self-hosted runner：git credential helper または askpass プログラムが `GIT_CONFIG` 経由で設定を読み取る際に、2.1.296 以降リポジトリアクセスが失敗していた問題を修正
- Self-hosted runner：バックグラウンドで起動されたランナーが出力を開いたままにしていると、オーケストレーターが spawn-runner フックをタイムアウトとして報告する問題を修正
- `/usage` の改善：各警告に原因を明記した1行の修正案が表示されるようになり、`f` で修正を適用できるようになりました。同様の修正案は VS Code や `/doctor` にも表示されます
