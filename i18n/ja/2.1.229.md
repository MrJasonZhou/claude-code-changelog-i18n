- 最新の Remote Control セッションを再開するための `claude remote-control --continue` をドキュメント化
- セルフホスト型 runner セッション向けにサーバー提供の Claude Code フック対応を追加し、マネージド環境の動作と統一
- 長時間の思考中におけるゲートウェイのストリーミングレスポンスに SSE キープアライブ ping を追加し、Vertex および Bedrock アップストリームでのアイドルタイムアウト切断を防止
- プラグインマーケットプレイスの `command` ソースを追加: ローカルコマンド（IDE など）がプラグインディレクトリを出力し、セッションごとに再解決されて再起動なしで適用。`mode: "link"` ではインプレースで使用
- `ListAgents` で切断された Remote Control セッションを `offline` とマークし、クラウドセッションに `cloud` ラベルを付与するように変更
- ストリーミング中に長いレスポンスの一部が消去され、ターミナルに2度出力される問題を修正
- ツール呼び出しに文字列以外の `glob`、`file_path`、または `command` の値が含まれていた場合にエラー画面へとクラッシュする問題（影響を受けたセッションの `--resume` 時を含む）を修正
- 非常に幅の狭いターミナルウィンドウでプログレスバーや Markdown テーブルを描画した際に RangeError でクラッシュする問題（起動時の `claude --continue`/`--resume` でもクラッシュする可能性があった問題）を修正
- Windows でツール呼び出しまたはメッセージが拡張長パス（`\\?\`）や UNC パスでファイルを参照した際にクラッシュする問題を修正
- `CLAUDE_CODE_ATTRIBUTION_HEADER` でアトリビューションヘッダーを無効にしているユーザー（直接の Anthropic API 接続）において、すべてのツール呼び出しで auto mode が失敗する問題を修正
- カスタムの `ANTHROPIC_BASE_URL` ゲートウェイを使用している claude.ai サブスクライバーに対して、`/model` が Sonnet/Opus 1M を拒否する問題を修正
- リダイレクト URI で `localhost` の代わりに `127.0.0.1` を使用することで、厳格な認可サーバーにおける MCP OAuth の問題を修正
- ラップトップのターミナルでスラッシュコマンドを入力した後に、Remote Control クライアントで処理中スピナーが停止したままになる問題を修正
- `/install-github-app` で生成された Claude Code Review ワークフローが、プルリクエストにレビューを投稿せずに完了してしまう問題を修正
- IDE 拡張機能の接続中に、数千件の IDE 診断結果を持つファイルを編集した後に UI が数秒間停止する問題を修正
- 単発の `claude plugin` コマンドが不要な liveness ファイルを残し、古いプラグインバージョンのクリーンアップを妨げる可能性があった問題を修正
- CPU 制限のあるコンテナ内の動的ワークフローが、コンテナの CPU 制限ではなくホストマシンのコア数を使用してしまう問題を修正
- 原子的ファイル置換後のファイルウォッチャーのハンドルリーク、およびネットワークや仮想ファイルシステム上でスケジュールタスクウォッチャーが失敗した際の Windows での未キャッチエラーを修正
- 空白のみのメッセージが送信された際に、SDK および `--input-format stream-json` セッションで 400 API エラーが発生する問題を修正
- メッセージ単体で API の 32 MB リクエスト制限を超えている会話において、削除可能な画像やドキュメントがないにもかかわらずコンパクションを再試行する問題を修正（明確なメッセージとともに1回で失敗するように変更）
- Claude Desktop セッションからの OpenTelemetry エクスポートが、ゲートウェイ自体がテレメトリエンドポイントでもある場合に Desktop 管理のゲートウェイによって拒否される問題を修正
- `managed-mcp.json` がデプロイされ、サーバーが MCP サーバーを配信している場合に、セルフホスト型 runner やその他のリモートセッションが起動時に終了する問題を修正（該当サーバーは警告付きでスキップ）
- セルフホスト型 runner のリポジトリ準備処理が Git Credential Manager のプロンプトでハングする問題を修正（認証情報がない場合は git が即座に失敗）
- ワークフローのファンアウトを改善し、同一プレフィックスを持つ兄弟エージェントの開始タイミングをずらすことで、後続のエージェントがプレフィックスを再計算せずキャッシュされたプロンプトプレフィックスを読み取るように改善（`CLAUDE_CODE_WORKFLOW_PREFIX_STAGGER_MS=0` で無効化可能）
- "prompt is too long" エラーを改善し、単に `/compact` を提案するだけでなく、自動コンパクションで復旧できなかった理由を説明するように改善
- サンドボックスを改善: ネットワークドメインリスト内の IPv6 リテラルを角括弧で囲むようにし（`[::1]:443`）、曖昧な表記はフェイルクローズとして処理され `/doctor` で検出されるように変更
- ログイン成功後に `CLAUDE_CODE_OAUTH_TOKEN` によるオーバーライド警告を再度表示するよう `/login` を更新
- 危険なフラグ（`--force`、`--amend`、`--no-verify` など）を含む git/gh コマンドが自動承認されないよう `/commit-push-pr` を変更
- Windows 上のセルフホスト型 runner の起動時に明示的な `--base-dir` を必須に変更（Windows にはデフォルトのチェックアウトディレクトリが存在しないため）
- [VSCode] "Report a problem" および `/bug` が、廃止されたアンケートリンクの代わりに組み込みのフィードバックダイアログを開くように変更
- [VSCode] サイドドックとスタックの両方のレイアウトで、境界線をドラッグして `/btw` の side-question パネルのサイズを変更できるように改善
- [VSCode] サイドバーにセッショングループを追加 — 右クリックで作成、名前変更、削除が可能。Cmd/Ctrl または Shift クリックで複数のセッションを一度に移動可能
