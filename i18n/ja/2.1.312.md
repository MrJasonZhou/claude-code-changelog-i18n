- git リポジトリ内で Bash の `cd` により深い階層へ移動した際、ディレクトリ単位のスキルや `paths:` スキルが見つからなくなる問題を修正
- ターミナルでセッションを再開した後の最初の応答が、次回セッション再開時に消失することがある稀な問題を修正
- 無効な名前のコマンドによって全コマンドの読み込みが停止し、`claude -p` の出力が空になることがある問題を修正
- 古いセッションファイルのクリーンアップが同時に実行された際、Read ツールが PDF ページで「pdftoppm failed: Could not write image」となって失敗することがある問題を修正

- 最後のメッセージの文中でユーザーの対応待ち項目に言及しただけで、一部のセッションがユーザーの対応待ちとして表示される問題を修正
- 終了直前に Ctrl+C でクリアされた入力テキストが、次回起動時に agent view で復元されてしまう問題を修正
- 空の `!` 入力から Ctrl+D で終了した後に、agent view がシェルモードで再起動してしまう問題を修正
- vim モードにおいて、残りの行数より大きいカウントを指定した `gj` や `gk` を伴う `d`、`c`、`y` がテキストを削除またはコピーしてしまう問題を修正。Vim と同様にカーソル移動のみを行うようになりました

- プロンプトの effort インジケーターを改善: タスク中の変更時に次のメッセージを待つ可能性がある旨が表示され、適用対象外になると注記が消去されるようになりました
- クラウドセッションにおける WebFetch エラーを改善: ホストの名前解決ができない場合、許可されたネットワークドメイン外である可能性がある旨が説明され、Claude が許可すべきホスト名を提示するようになりました

- メッセージがフラグ付けされた後の自動モデル切り替えを、カスタムデプロイ名など Claude Code が認識しないモデル名にも適用されるように変更。無効化するには `CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1` を設定してください

- CLI から開始されたクラウドセッションの名前およびブランチ名をサーバーから取得するように変更
- プロンプトおよびエージェントのフック実行を、サブエージェントを含めセッションあたり同時に最大 24 個、さらにイベントのタイムアウトを超えて待機しているものは最大 12 個までに制限。1秒未満の `timeout` は 1 秒としてカウントされるようになりました
