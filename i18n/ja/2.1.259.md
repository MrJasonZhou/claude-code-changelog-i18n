- `managedMcpServers` 管理設定を追加: 組織はすべてのユーザーに HTTP/SSE MCP サーバーを提供可能（`.mcp.json` と同じエントリ形式）。実行するコマンドを指定するエントリはスキップされます
- 無人ヘッドレスホスト向けに `--permission-prompts none` を追加: プロンプト表示を伴う操作は自動的に拒否され、アクティブな権限モード（auto モードを含む）による判定は継続されます
- `glab mr create/merge/close/reopen/note/update` の認識を追加: GitLab マージリクエストが折りたたまれたツール概要に `MR !N` として表示され、フッターの MR バッジが更新されるようになりました
- `claude plugin validate` に機械可読な検証レポートを出力する `--json` を追加
- 同時実行セッション間で `~/.claude.json` の変更が警告なく元に戻される問題を修正: 多数のセッションを同時に実行しても、ワークスペースの信頼状態がリセットされたり MCP/プロジェクトの状態が失われたりしなくなりました
- 思考プロセスが一度拒否された会話において、それ以降のすべてのターンで再び拒否されてしまう問題を修正
- Bash の `Read()` 拒否ルールが、オプション値として指定されたファイル（`--ignore-revs-file=.env`、`-f.env`、`@file`）、`git diff`/`git grep` のファイルオペランド、`cd DIR && cat FILE` などの複合コマンドをカバーしていなかった問題を修正。拒否対象ファイルを含むディレクトリに対する `grep -r`/`cp -r` では確認プロンプトが表示されるようになりました
- テレメトリが無効化されたセッションで OAuth トークンが更新された際に、プロンプトキャッシュが無効化されてしまう問題を修正
- 数百件のツール呼び出しを伴う長いターンの後、フルスクリーンモードで会話が空白で表示される問題を修正
- コマンドやスキルの frontmatter `model:` で指定されている場合に、auto モードが非対応モデルでターンを実行してしまう問題を修正。セッションのモデルが維持されるようになりました
- Claude Code が認識しないモデルバージョンの Vertex 形式モデル ID（`@YYYYMMDD` 接尾辞）で `CLAUDE_CODE_MAX_CONTEXT_TOKENS` が無視される問題を修正
- 実行中のシェルコマンドのライブ出力プレビューにおいて、前の行が折り返された際に最新の行が隠れてしまう問題を修正
- claude.ai ユーザーにおいて起動のたびに実行されていたバックグラウンドの GitHub 接続チェックを修正。起動をまたいで結果が保持されるようになりました
- 保存されたセッションにペイロードのないアタッチメントエントリが含まれている場合、`--resume` が失敗する（および `--continue` で空の会話が開く）問題を修正
- 対話型セッションでカスタムコマンドやスキルの frontmatter `model:` が無視される問題を修正
- 古いバージョンから引き継いだ会話において、Artifact の公開が「unexpected parameter `note`」エラーで一度失敗する問題を修正
- MDM または管理設定ファイルによって設定されたポリシーヘルパーがすでに実行されていた場合、起動時に管理対象の `forceRemoteSettingsRefresh` が無視される問題を修正
- `git rev-parse` が「not a git repository」以外のメッセージで失敗するマシンにおいて、ワークツリー分離がフックによって作成されたワークツリーを拒否する問題を修正
- クラウドセッションからの OpenTelemetry メトリクスおよびイベントで `user.email`、`organization.id`、`user.account_uuid` 属性が欠落していた問題を修正
- 起動時にツールのリスト取得中に切断された MCP サーバーが、エラーを報告せずツールなしの接続済み状態として表示される問題を修正
- ファイル編集の権限ダイアログで、変更された行が何も表示されずに途中で切れてしまうことがある問題を修正
- 一時的な git 検出エラーの後、リポジトリ検出によって既知のリポジトリ識別情報が破棄されてしまう問題を修正
- 管理設定ファイル、ドロップイン、MDM の plist、または HKLM の値がパースできない場合に、管理設定が通知なく未適用になる問題を修正: Claude Code の起動が拒否され、原因となったソースが表示されるようになりました
- リモートコントロールセッションで Stop を実行してもバックグラウンドエージェントやワークフローが実際には停止しなかった問題を修正: 強制終了されたタスクは、プロセスが終了するまで表示されたままとなり再停止可能になりました
- ワークフローの実行を再開する際、以前の停止された実行が終了処理中であるとエージェントが重複して実行される可能性がある問題を修正
- 末尾にスラッシュや不要な `?`/`#` が付いた github.com 上のマーケットプレイスリポジトリ URL から、使用不能な `.git` クローン URL が生成される問題を修正
- ブロッキング Stop フックにより、ブロック後のターンでそのターンのモデルの推論内容が失われ、一部のモデルでプロンプトキャッシュミスが発生する問題を修正
- ブラウザホストの MCP サーバーのページが消去された後、リモート（claude.ai）セッションがターンを開始するまでに 60 秒かかっていた問題を修正
- ワークツリー分離されたセッションが、メインのチェックアウトに到達できない一般的な Bash ループ、xargs パイプライン、ランチャーでラップされたコマンドを拒否する問題を修正
- テキストの測定結果を再利用することで、長いレスポンスに対するターミナルのリサイズおよび初回レンダリングのパフォーマンスを改善
- `/workflows` のエージェント詳細を改善: JSON 結果がシンタックスハイライトと実際の改行を伴って整形表示され、長い結果は展開トグル内に折りたたまれるようになりました
- ヘッドレス/SDK セッションの起動を改善: MCP サーバーの接続完了時、最初のターンが最大 50 ms 早く開始されるようになりました
- GitLab リポジトリ内で実行された場合、`/install-github-app` が GitHub 専用であることを説明し、GitLab CI/CD ドキュメントを案内するように改善
- ネストされたバックグラウンドサブエージェントの結果が親サブエージェントのトランスクリプトに保存されるように改善。再開されたサブエージェントが結果を保持し、共有トランスクリプトに配信状況が表示されるようになりました
- `allowedMcpServers` の対象をユーザーが追加したサーバーのみに限定するよう変更: 許可リストによって以前除外されていたリテラルの `managed-mcp.json` サーバーがアップグレード時にロードされるようになりました。無効にしておくには `deniedMcpServers` を使用してください
- [VSCode] セッション一覧サイドバーに Active クイックフィルターとステータスフィルターメニュー（Needs input、Working、Completed）を追加
- セッションの一時停止中にコネクターツールの権限プロンプトが承認された後、リモートおよびスケジュールされたセッションが何も実行しなくなる問題を修正
