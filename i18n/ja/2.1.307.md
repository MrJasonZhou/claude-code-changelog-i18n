- Claude API のコードを API バージョン `2026-10-21` に移行する `/claude-api api-version` を追加
- パーミッションルール、auto mode、セーフティチェック、hook、またはサンドボックスによって停止、確認のプロンプト表示、または差し戻しが行われたツール呼び出しごとに記録される `claude_code.safety_event` OpenTelemetry イベントを追加
- `CLAUDE_CODE_DISABLE_1M_CONTEXT` が設定されており、モデルが `opus[1m]` などの `[1m]` サフィックスを持つエイリアスの場合に、リクエストが model-not-found エラーで失敗する問題を修正
- 効果のないカスタム `ANTHROPIC_BASE_URL` ゲートウェイ経由および Foundry 上において、`prompt-caching-scope` ベータヘッダーが送信される問題を修正
- macOS 上の `claude -p` でログインキーチェーンがロックされている際、MCP サーバーが「needs authentication」と表示される問題を修正。理由が表示されるようになり、ロック解除後の次回の実行時には再サインインなしで接続可能に
- macOS または Linux マシンが接続中にスリープ状態になった際、MCP サーバーがタイムアウトと報告され、ヘッドレス実行で失敗したままになる問題を修正
- 通話途中で接続が切断された際に HTTP MCP ツール呼び出しが重複送信される問題を修正。読み取り専用または冪等（idempotent）なツールのみが再試行されるように変更
- バックグラウンドタスクの実行中に、SDK MCP サーバーの最新ツールがない状態でターンが開始することがある問題を修正
- 多数の PDF ページ、画像、その他の大きなツール実行結果を読み込んだターンで発生する一部の「Autocompact is thrashing」エラーを修正
- クラウドセッションでの `/autocompact` が、セッション再起動後にデフォルトのウィンドウサイズに戻ってしまう問題を修正
- `/clear` でクリアされた会話が、クラウドまたはセルフホスト runner セッションの再起動後に復元してしまうことがある問題を修正
- Claude apps ゲートウェイセッションで `CLAUDE_STREAM_FIRST_BYTE_TIMEOUT_MS` が無視される問題を修正
- Claude apps ゲートウェイ経由の Claude Desktop セッションからのテレメトリが、`OTEL_EXPORTER_OTLP_HEADERS` 設定時に拒否される問題を修正
- `/permissions` > Recently denied で拒否されたシェルコマンドが表示されず、再試行されたコマンドの検証時に auto mode のローカル分類器がここでの承認を無視する問題を修正。行の承認時に説明文ではなくコマンド名が表示されるように変更
- `/help` や `/` コマンドメニューで、`/claude-api` などのバンドルされたスキルの短い説明ではなく、モデル向けの詳細な説明が表示される問題を修正
- ストリーミングレスポンスにおいて、サブエージェントのトランスクリプトにプレースホルダーのトークン使用量と空の停止理由が記録される問題を修正
- API によるモデル確認に 5 秒以上かかった際、Agent SDK の `setModel()` およびこれを用いて構築されたアプリからのモデル切り替えが拒否される問題を修正。Claude Code は最大 15 秒待機するように変更
- 接続済みアプリを介して停止されたバックグラウンドコマンド（アイドルセッションをアーカイブするデスクトップアプリなど）が、ユーザーによって停止されたと Claude に報告される問題を修正。通知に出力ファイル名が表示されるように変更
- Cowork クラウドセッションの WebFetch において、サイトが 4xx ステータスまたは robots.txt による拒否を返した際にツールエラーとして報告される問題を修正。ローカルセッションと同様に通常の結果として処理されるように変更
- 直接設定された GitHub MCP サーバーの書き込みツールで、デスクトップアプリの Code タブに何も作成されずにフォームが閉じてしまう問題を修正
- サーバー側が再利用された接続を切断した際、Artifact ツールの読み取りが connection reset で失敗する問題を修正
- セルフホスト runner: `--use-anthropic-git-proxy` を使用するセッションが、過去のセッションによってクローン内に残された `.claude/settings.local.json` をコミットしてしまう問題を修正
- セルフホスト runner: チェックアウト hook の実行中にセッションのアーカイブや再キューイング、または runner の停止を行った際、hook のプロセスが実行されたままになり runner のスロットが占有され続ける問題を修正
- パース不可能なツール呼び出しからのリカバリを改善: エラーでターンを終了する前に、Claude Code が最大 2 回まで呼び出しを再試行するように変更
- 同時に起動された fork サブエージェントの処理を改善: 各サブエージェントに自身の起動インスタンスが通知されるようになり、fork 同士がお互いのタスクを開始してしまう可能性を大幅に低減
- ブラウザサインインの改善: アカウントプロファイルの読み込みを待つことなく、サインイン完了後すぐに成功画面が表示されるように変更
- クラウドおよびセルフホスト runner セッションにおけるウェブ検索エラーを改善: 理由付きの 403 で拒否された検索において、汎用的な「Authentication error」ではなくその理由を表示するように変更
- デスクトップアプリのいずれかの MCP サーバーが接続できない場合における、クラウドセッションの初回応答までの時間を短縮
- トランスクリプトに大量の貼り付け画像や PDF の読み取り内容が含まれるセッションにおける、Remote Control の接続時間を短縮
- WebSearch のバジェットを使い切った際に Claude に送られる通知を変更し、ブラウザ経由や computer use で検索エンジンに問い合わせないよう指示を追加
- 設定の `env` ブロック内の `axScreenReader` 設定および `CLAUDE_AX_SCREEN_READER` が、ユーザー設定、管理設定、または `--settings` からのみ適用されるよう変更（2.1.305 以降）
- セルフホスト runner: チェックアウト hook がデフォルトで 30 分後に停止され、セッションのセットアップが失敗するよう変更。より長時間の実行が必要な場合は `--checkout-hook-timeout-min` を増やすか `0` に設定してください
- セルフホスト runner: Anthropic 管理の git 向けに生成される証明書ファイルが、CLI と同様に信頼済み証明書をフィルタリングするよう変更。除外された数は `[runner:warn]` 行で出力
- [VSCode] 音声入力が自動停止した際（認識可能な発話がない状態が 15 秒続く、または 2 分の制限に達した際）、マイクボタンにその理由とそれまでのテキストが保持されている旨の通知を追加
- [VSCode] 「Show more」で展開された長いプロンプトがチャットパネル全体を覆ってしまう問題を修正。固定されたプロンプトはパネルの最大 40% に制限され、スクロール可能に
- [VSCode] LaTeX 数式を含むリストアイテムやテーブルセルの部分が、リッチテキストエディタで新しいリストやテーブルとして貼り付けられる問題を修正
- [VSCode] `~/.claude/settings.json` のみで `NODE_EXTRA_CA_CERTS` が設定されている場合、TLS インスペクションプロキシ環境下で音声入力が失敗する問題を修正。`CLAUDE_CODE_CERT_STORE` も参照するように変更
- [VSCode] 「still open somewhere else」の通知対象を拡張し、拡張機能の再起動後に残存した Claude プロセス（通常は約 10 分以内に自動終了）もカバーするように変更
- [VSCode] 音声入力において、CLI と同様に信頼済み証明書をフィルタリングするよう変更
- [VSCode] 拡張機能自体のリクエストにおいて、CLI と同様に信頼済み証明書をフィルタリングし、環境変数またはユーザー設定で指定された `NODE_EXTRA_CA_CERTS` ファイルを信頼するよう変更
- [クラウドセッション] 検索実行中にもかかわらずリポジトリピッカーが「No repositories match」と表示する問題を修正。結果が返るまで「Searching…」と表示されるように変更
- [クラウドセッション] セルフホスト環境における「Waiting for a runner」ステータスが途切れる問題を修正。オンデマンド runner では最後のメッセージからの経過時間をカウントし、失敗した試行回数を表示するように変更
- [Code Review] Code Review に `@claude review stop`（`off` および `pause` も可）を追加。プルリクエストに対する `@claude review always` のサブスクリプションを、新たなレビューを開始することなく解除可能に
