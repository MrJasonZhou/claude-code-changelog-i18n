- 클라우드 세션 개선: 새 대화의 첫 번째 턴이 설정에서 `alwaysLoad: false`로 지정된 stdio MCP 서버를 더 이상 기다리지 않습니다.
- "You should know" 알림 개선: 결정에 책임이 있는 주체에 따라 "we", "the main agent" 또는 "you"로 표시됩니다.
- 데이터베이스 크기 제한으로 아티팩트 데이터베이스 쓰기가 거부될 때의 오류 개선: 이제 제한 크기와 공간을 확보하는 방법을 명시합니다.
- 명령어가 실행되기 전에 일부를 확인할 수 없을 때 더 짧은 이유를 제공하도록 Bash 권한 프롬프트를 개선했습니다.
- 자체 호스팅 러너: 내장 `gh api` 개선: 거부된 gh 명령어는 이에 해당하는 `gh api`를 출력하고, `--paginate`는 저장소 목록의 모든 페이지를 탐색하며, 중첩된 `claude`가 이를 더 이상 제거하지 않습니다.
- 만료된 서버 자격 증명에 대한 Remote Control의 복구 개선: 갱신 중에도 세션이 연결된 상태를 유지하며, 서버 중단 후 포기하더라도 세션이 유지됩니다.
- 백그라운드 명령어 시간 제한이 무인 세션(`-p`, Agent SDK, CI, 클라우드)에만 적용되도록 변경했습니다. 터미널, 데스크톱 앱 및 VS Code 세션에는 제한이 없습니다.
- 클라이언트 측 자동 모드 분류기가 Claude Sonnet 5.5 또는 Opus 5.5를 지정하는 `ANTHROPIC_DEFAULT_SONNET_MODEL` 고정을 무시하고 Claude Sonnet 5를 대신 사용하도록 변경했습니다.
- `claude project purge`를 `claude purge`로 변경했습니다. 이전 이름도 계속 작동하며 안내를 출력합니다.
- 에이전트 뷰의 `n:` 필터(및 Ctrl+F 검색)에서 Enter 키를 누르면 맨 위 행 대신 이름이 가장 잘 일치하는 세션이 열리도록 변경했습니다.
- 모델 전환 시 각 모델의 설정이 유지되도록 `/autocompact`가 모델별로 자동 압축 창을 저장하도록 변경했습니다.
- 작업 완료 시점을 보고할 수 없는 서버의 MCP URL 프롬프트가 도구 호출을 계속하기 전에 "I'm done, continue" 입력을 기다리도록 변경하여 브라우저에서 먼저 완료할 수 있게 했습니다.
- [VSCode] 권한을 부여한 후에도 claude.ai 커넥터가 "Needs authentication" 상태로 유지되던 문제를 수정했습니다. 이제 MCP 서버 대화 상자에서 Check connection 기능을 제공합니다.
- [VSCode] 옵트인 새 대화 단축키(Cmd/Ctrl+N)가 현재 위치한 뷰만이 아닌 표시된 모든 Claude 뷰에서 대화를 시작하던 문제를 수정했습니다.
- [VSCode] 채팅 뷰에서 표시 중인 세션을 아카이브한 후 다음에 저장된 세션을 재개하던 문제를 수정했습니다. 이제 대신 새 대화를 시작합니다.
- [Cloud sessions] 관련 없는 보안 설정이 로드 중이거나 로드에 실패했을 때 Claude Code 관리자 설정의 Cloud sessions 스위치가 꺼진 상태로 고정되던 문제를 수정했습니다.
