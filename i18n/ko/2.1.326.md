- 프로그램이 Windows 백슬래시 경로인 와일드카드 허용 규칙을 auto mode가 판단하여 해당 호출을 차단할 수 있도록 변경 (정확한 일치 규칙은 허용 유지, `.\`로 시작하는 규칙은 복원 예정)

- 로컬 터미널 세션의 `--add-dir` 및 `/add-dir`에서 아직 신뢰하지 않은 폴더에 대해 신뢰 프롬프트를 표시하도록 변경 (`claude --bg`는 해당 폴더를 거부함)

- Remote Control 및 자체 호스팅 러너에서 권한 응답 시 "always allow" 선택을 저장하는 방식 변경
- 잘못된 형식의 `plugin.json` 표시 필드로 인해 거부되었던 활성화된 플러그인이 훅 및 MCP 서버와 함께 로드되도록 변경 (관리자는 배포하는 플러그인을 점검할 것)
- 관리형 설정의 훅에 `allowedHttpHookUrls` 및 `httpHookAllowedEnvVars`가 적용되는 방식 변경

- 다른 플러그인이 동일한 번들을 사용하지 않는 한 플러그인 제거 시 플러그인의 MCP 번들(`.mcpb`, `.dxt`)에서 추출된 파일도 함께 삭제되도록 변경

- Remote Control: 프록시를 통한 연결 방식 변경: 요청에 이제 CONNECT 터널을 사용하므로 CONNECT를 거부하는 프록시의 경우 Remote Control이 오류와 함께 중단됨
