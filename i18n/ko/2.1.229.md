- 리디렉션 URI에서 `localhost` 대신 `127.0.0.1`을 사용하여 엄격한 인가 서버와의 MCP OAuth 문제 수정

- IDE 확장이 연결되어 있을 때 수천 개의 IDE 진단(diagnostics)이 포함된 파일을 편집한 후 UI가 몇 초 동안 멈추던 현상 수정
