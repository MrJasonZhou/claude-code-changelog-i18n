- Self-hosted runner: 세션이 새 러너로 이동하고 해당 턴이 `CLAUDE_CODE_RESUME_INTERRUPTED_TURN_MAX_AGE_MS`보다 오래되었을 때 Claude가 중단된 도구 호출을 인식하지 못하던 문제를 수정했습니다.
- Self-hosted runner: 세션 서비스가 전환 설정 저장을 거부한 상태에서 세션이 새 머신으로 이동한 후 꺼져 있던 MCP 서버가 다시 켜지던 문제를 수정했습니다.
- Remote Control: 앱에서 별도 이름을 지정하지 않았을 때의 포크 이름을 개선했습니다. 긴 이름에는 "(fork)" 접미사가 유지되며, `claude remote-control`로 시작된 세션에서 "Name (fork)"의 포크는 "Name (fork 2)"가 됩니다.
- [VSCode] 포크된 대화에서 메시지가 누락되던 문제를 수정했습니다. Claude가 병렬로 실행한 도구 호출 중 하나만 유지되고 압축 시 보존된 마지막 메시지가 손실되어 질문 없는 답변만 남을 수 있던 문제를 해결했습니다.
- [VSCode] Claude가 제시간에 시작을 완료하지 못했을 때 메시지가 유실되던 문제를 수정했습니다. 이제 확장 프로그램이 오류를 표시하기 전에 Claude를 한 번 더 시작합니다.
- [VSCode] 지역 또는 네트워크 문제로 요청이 차단되었을 때 로그인 화면이 열리던 문제를 수정했습니다.
- [VSCode] Account 패널에서 플랜 이름의 두 번째 단어가 소문자로 표시되던 문제를 수정했습니다.
- [VSCode] Claude 탭의 파일 링크가 다른 에디터 그룹 대신 채팅 화면 위에 열리던 문제를 수정했습니다.
- [VSCode] `chat.fontSize`를 키웠을 때 Claude 패널의 첨부 파일 칩, 메뉴, 배너, 대화 상자 크기가 작게 유지되던 문제를 수정했습니다.
- [VSCode] 텔레메트리가 꺼져 있을 때 `ultrathink`가 해당 턴의 effort를 높이지 않거나 레인보우 효과를 표시하지 않던 문제를 수정했습니다.
- [Cloud sessions] 클라우드 세션에 링크 카드를 추가하여, MCP 서버가 방문을 요청하는 링크를 요청이 누락되지 않고 열거나 거부할 수 있도록 개선했습니다.
- [Cloud sessions] 관리자 설정의 조직 환경 대화 상자를 개인 대화 상자의 간단한 레이아웃으로 변경했습니다. 각 섹션은 행 단위로 열리며 저장되지 않은 입력이 있을 경우 닫기 전에 확인합니다.
- [Cloud sessions] 이미 시크릿이 존재하는 호스트에 네트워크 시크릿을 추가할 때 경고 없이 덮어쓰던 문제를 수정했습니다. 이제 Add secret 양식에서 이를 거부하고 기존 시크릿을 안내합니다.
- [Cloud sessions] 새 예약 작업이 조직의 기본 환경을 무시하던 문제를 수정했습니다. 이제 양식이 Anthropic 호스팅 기본값 대신 관리자가 선택한 환경에서 시작됩니다.
- [Remote Control] `claude remote-control`을 재시작한 후 이전 메시지를 보낸 지 1분 이내에 유휴 세션으로 새 메시지를 보냈을 때 응답이 없던 문제를 수정했습니다.
- [Claude Tag] Slack에 새로 붙여넣은 아티팩트 링크가 Slack 사이드 패널 대신 Claude에서 아티팩트를 여는 Open 버튼이 포함된 단순한 카드로 표시되도록 변경했습니다.
